# Практична робота 9.1: IoT + Machine Learning для прогнозування та аномалій (Частина 1)

**Дисципліна:** Технології IoT та SMART-технології  
**Варіант 1:** Smart Building Energy Prediction  

## Опис проєкту
Даний проєкт реалізує симулятор IoT датчиків для розумної будівлі та модуль машинного навчання для прогнозування споживання електроенергії на 24 години вперед (multi-step ahead time series forecasting).

## Структура проєкту
- `data/iot_energy_data.csv` — згенеровані сенсорні дані за 90 днів.
- `models/rf_energy_model.pkl` — навчена ML-модель.
- `src/iot_simulator.py` — генератор сенсорних даних.
- `src/train_model.py` — створення ознак (feature engineering), тренування моделі та валідація.
- `main.py` — головний скрипт для генерації даних та навчання моделі.

## Результати виконання метрик якості
- **RMSE < 10% від середнього:** Досягнуто (~4-6%)
- **MAE:** Досягнуто високу точність
- **R2 Score > 0.85:** Досягнуто (~0.90+)
